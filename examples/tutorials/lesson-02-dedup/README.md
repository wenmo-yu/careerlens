# 练习 02 · 验证去重

**对应课程**：[03 解析层](../../../tutorials/03-parsing.md)
**核对什么**：同用户导入两次比对 ID；不同用户不复用。

## 运行

```bash
python3 examples/tutorials/lesson-02-dedup/main.py
```

## 预期输出

```text
用户 A 第一次：<ID>
用户 A 第二次：<同一个 ID>
用户 B 同内容：<另一个 ID>
OK：去重按「用户 + 规范化文本」生效。
```

## 它验证了什么

去重键是 `(user_id, content_hash)` 的数据库唯一索引；`content_hash` 只对规范化后的文本算 sha256。所以：

- 同一用户、同一段文字 → 复用同一条 Evidence，不会新建；
- 不同用户、同一段文字 → 各自建各自的证据（用户隔离）。

脚本用两个专用教学用户，避免影响别的数据。

## 常见情况

- 若第一次运行就报错连不上服务，见 [FAQ 启动类](../../../tutorials/FAQ.md#启动与安装)。
- 换 `source_name` 不改内容，ID 仍相同——新来源会被追加到证据的来源列表里。
