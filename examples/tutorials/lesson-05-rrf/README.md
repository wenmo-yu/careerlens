# 练习 05：手算排名融合（RRF）

对应样板课：[04 · 为什么这条证据排第一，却不能支持这句结论](../../../tutorials/04-retrieval-agent.md)。

这个练习**不需要服务、不需要安装**，只用 Python 标准库。它把真实检索里「合并两张榜单」的步骤缩成一个能手算的玩具，让你先搞懂公式，再去看服务里发生了什么。

## 运行

```bash
python3 examples/tutorials/lesson-05-rrf/main.py
```

Windows 用 `py examples/tutorials/lesson-05-rrf/main.py`。成功打印 `OK：...` 并退出 0。

## 你要做的四步

| 步骤 | 你先做 | 脚本核对 |
| --- | --- | --- |
| 1 · 先猜 | 看 `LIST_A`/`LIST_B` 两张榜，用手算 `1/(k+名次)` 猜谁第一（名次从 0 数，`k=2`）。 | B 两榜都命中，分数 `2/3`，高于只中一榜榜首的 A、C（各 `1/2`）。 |
| 2 · 改变量 | 把 B 从榜单 A 移除，再猜顺序。 | B 掉到 `1/3`，不再是第一。 |
| 3 · 名次交错 | 猜 `rank_interleave` 输出，和分数融合比。 | 交错是 `['A','C','B']`，依据和分数融合不同。 |
| 4 · 判错 | B 排第一，但它是一条「收藏教程」式的兴趣线索，能支持「做过上线」吗？ | 不能，应写「证据不足」。 |

## 两条边界（很重要）

- **玩具参数**：`k=2`、名次从 0 数，是为了手算方便。真实服务用 Qdrant 服务端的原生 RRF，源码没有显式指定 `k`；不同排名约定（从 0 还是从 1 数）下常数不能直接套。别把 `2/3`、`1/2` 当成 CareerLens 的实际分数。
- **分数 ≠ 支持**：RRF 只回答「在两张榜里排第几」，不回答「这条材料能不能作为结论的依据」。榜首也可能是兴趣线索——这正是样板课要你分清的第三件事。
