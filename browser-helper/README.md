# CareerLens 本地页面采集

这个 Chrome/Edge MV3 扩展让用户在自己的浏览器中登录 Bilibili、微博或抖音，然后**主动**从当前已加载页面导出发布、点赞、收藏或关注条目的可见文字与链接。扩展不读取 Cookie、Local Storage、密码或网络请求，也不会自动向 CareerLens 或第三方发送数据。它不是官方 OAuth，也不是可保证完整覆盖的账号历史导出。

## 使用

1. 在 Chrome 或 Edge 的“管理扩展程序”中开启开发者模式，选择“加载已解压的扩展程序”，指向仓库的 `browser-helper/` 文件夹。
2. 在平台**自己的账号页面**登录，打开发布内容、点赞、收藏或关注页面，并手动滚动加载需要的条目。
3. 点击扩展图标，选择当前页面类型，点击“把当前页面加入采集清单”。滚动加载或切换页面后可以重复采集。同一平台与页面类型的条目会按链接合并；每次采集最多读取 100 条，一个分组最多保留 200 条。
4. 在扩展中切换已采集分组，移除误采条目，再导出该分组的 JSON。采集清单只暂存在浏览器扩展的会话内存中；关闭浏览器、停用或重载扩展后会清空。
5. 在 CareerLens 工作台的 **Browser Capture** 卡片选择 JSON，逐条勾选要保留的记录，再点击“确认导入”。取消时不会写入。后端还会核对格式、平台域名并去重；点赞、收藏、关注只作为兴趣线索，不直接证明技能或经历。

导出的 JSON 可能包含你不希望公开的页面文字；请在上传前检查文件，**不要把真实采集文件提交到 GitHub**。若页面结构变化、站点阻止扩展读取或未加载任何卡片，扩展会提示无法采集，不会尝试绕过平台限制。不要用它采集私信、其他人的私密内容或批量爬取他人账号。

## 当前边界

- 采集器仅分析用户当前浏览器标签页的 DOM；它不会自动翻页、后台轮询或读取登录凭证。
- 各平台页面结构可能变化，尤其动态加载或虚拟列表会让已滚出页面的条目不可见。需要人工核对导出数量和内容。
- “自己的发布内容”由用户选择，平台未向 CareerLens 证明账号归属；该类证据仍须用户核对。
- 对账号长期同步应采用平台正式授权接口。官方权限并不保证开放完整的点赞、收藏或关注历史，需逐项申请并核对范围。
