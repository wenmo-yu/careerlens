# Community Code of Conduct

This applies to discussions, issues, reviews, and other CareerLens project spaces.

- Treat people respectfully. Critique ideas or code, not the person who wrote them.
- Welcome questions and include enough context for contributors with different backgrounds.
- Do not harass, discriminate, threaten, or publish someone else's private information.

Report concerns to the maintainer through a private channel when available. If you do not
have one, ask for a private contact route without posting the incident or anyone's personal
information in a public issue. Maintainers may remove abusive content or restrict participation
to protect contributors. Report security vulnerabilities through [the security policy](SECURITY.md).
