## 自查

- [ ] 实验写清了固定输入、改的一个变量、改前的预测、实际结果和原因
- [ ] 有一个负例，能说明规则真的在起作用（不是碰巧通过）
- [ ] 别人按我写的版本和命令能重跑出同样的结果
- [ ] 每条结论都能点回证据 ID，且证据 ID 追得到原文
- [ ] 区分了「证据支持」和「推测」，没把做过写成熟练
- [ ] 缺口写的是「证据不足」，没有脑补
- [ ] 下一步对应缺口，不是凭空安排
- [ ] 写明了合成材料、复现版本和未验证项
- [ ] 没有贴真实个人资料或密钥

评分看四件事：**实验能否复算、引用能否追溯、能否区分证据与推测、失败能否解释**。不按术语数量或报告长短给分。

提交方式见 [08-3 贡献与结课](08-advanced/08-3-contribute.md)。
