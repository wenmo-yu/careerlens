## 自查

- [ ] 每条结论都能点回证据 ID，且证据 ID 追得到原文
- [ ] 区分了「证据支持」和「推测」，没把做过写成熟练
- [ ] 缺口写的是「证据不足」，没有脑补
- [ ] 下一步对应缺口，不是凭空安排
- [ ] 写明了合成材料、复现版本和未验证项
- [ ] 没有贴真实个人资料或密钥

评分看三件事：**能否追溯引用、能否区分证据与推测、下一步是否对应缺口**。不按术语数量或报告长短给分。
