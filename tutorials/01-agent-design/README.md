# 3. 读 Agent 源码

从林澈的一句话开始，在一份独立练习副本中写回 CareerLens 的 Agent 核心。原项目用到的数据库模型、测试和周边代码已经备好。每课从技术原理和仓库相对路径讲起，先用一组实际输入读懂关键几行，再按练习文件里的代码提示补写。浏览器读者可以直接点源码，动手读者最后会启动自己的 API 和 Worker。

## 这段课怎么读

每一关集中补写一组真实函数。表里列了顺序，每课会告诉你该打开练习副本里的哪个文件、测试应该看到什么。跟敲时，按这几个动作走。

1. **这一关在整条链里的位置**——先知道它在做什么、为什么需要这一层。
2. **原理拆解**——把涉及的技术词、设计取舍讲清楚，配一张图。
3. **逐块写代码**——按练习文件里的 `#` 注释补函数，边写边对照真实实现。
4. **失败反推表**——测试报什么错，最可能是哪一步漏了。
5. **常见坑 + 项目对照表**——把这一关的词落回真实源码位置。

读源码和敲代码可以混着来：只想理解，就读原理和真实实现；想动手，就按 `open` / `check` 走完整循环。

## 每关的练习命令

| 命令 | 作用 |
| --- | --- |
| `python tutorials/01-agent-design/lab/practice.py new` | 创建一份独立练习副本（只做一次） |
| `... practice.py open <关卡>` | 把该关函数换成 TODO + 提示注释 |
| `... practice.py check <关卡>` | 在副本里跑对应的真实 pytest |
| `... practice.py check all` | 跑全部关卡的测试 |
| `... practice.py serve` | 用副本启动 API（8030 端口） |
| `... practice.py worker` | 用副本启动后台 Worker |

八关名依次是：`state`、`routing`、`retrieval`、`tools`、`answer`、`conversation`、`memory`、`coordinator`。 [练习启动器](lab/practice.py)

## 两条阅读路线

- **只用浏览器**：跟着每篇的原理、真实实现折叠块和 Mermaid 图走，知识点和动手路线完全对应，只是不写码。
- **动手敲**：按 01-A 准备 Python 3.11+ 与练习副本，从 `open state` 开始逐关 `check`。每次 `open` 后，在终端打印的练习路径补代码，仓库里同名文件用来查原始实现。主线使用 Demo 和合成数据，无需 Docker、API 密钥或下载模型。

两条路在每一关都会同时给出「原理讲解」和「真实实现」，随时可以切换。 [从第 1 课开始](01-A-Agent工作流.md)
