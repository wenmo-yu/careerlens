# 3. 读 Agent 源码

从林澈的一句话开始，在一份独立练习副本中写回 CareerLens 的 Agent 核心。原项目用到的数据库模型、测试和周边代码已经备好。每课从技术原理和仓库相对路径讲起，先用一组实际输入读懂关键几行，再按练习文件里的代码提示补写。浏览器读者可以直接点源码，动手读者最后会启动自己的 API 和 Worker。

| 顺序 | 课 | 这一关完成什么 |
| --- | --- | --- |
| 1 | [01-A 准备练习副本](01-A-Agent工作流.md) | 从工作台找到 `POST /api/v1/chat`，搭好能运行的本地起点 |
| 2 | [01-A1 写请求与状态](01-A1-请求与状态.md) | 写出 `run_career_graph`，把真实问题和用户资料交给图 |
| 3 | [01-A2 写状态图的路由](01-A2-路由与结束条件.md) | 实现分类和两个分支函数，核对有分析和无分析的出口 |
| 4 | [01-B 写检索工具](01-B-工具调用.md) | 实现图内的检索节点和三种资料模式，查回原文 |
| 5 | [01-B0 用 @mcp.tool 注册并调用工具](01-B0-注册与调用MCP工具.md) | 敲真实 `get_evidence`，通过 MCP 和 LangChain `@tool` 各查一次 |
| 6 | [模型配置](模型配置.md) | 先跑一次 Demo 对照，再选做兼容 API 或本地 Ollama，用诊断确认来源 |
| 7 | [01-B1 写模型答复与引用](01-B1-模型答复与引用.md) | 准备上下文，验证模型返回的引用，跑一次失败回退 |
| 8 | [01-B2 写两轮会话](01-B2-会话与画像确认.md) | 从网页把 `thread_id` 传到数据库，保存并读回四条消息 |
| 9 | [01-B3 写长期画像确认](01-B3-长期画像与确认.md) | 写草案和决定，测试批准、拒绝和提交失败的情况 |
| 10 | [01-C 写 Coordinator 与子 Agent](01-C-子Agent.md) | 把岗位任务交给两个角色，控制预算和提交 |
| 11 | [01-D 启动并验收](01-D-综合跟做.md) | 启动练习副本的 API 和 Worker，跑完一份资料的完整请求 |

主线练习只需 Python，使用 Demo 跑测试，无需 Docker、API 密钥或下载模型。各课沿用同一份练习副本。课程入口会带你区分「在仓库中读哪个文件」和「在练习中改哪个文件」。 [从第 1 课开始](01-A-Agent工作流.md)
