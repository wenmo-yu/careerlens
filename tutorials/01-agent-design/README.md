# 3. 读 Agent 源码

这一段跟着林澈的一次提问走进 CareerLens。学完可以看到一个真实 Agent 怎样接收请求、组织上下文、选择节点、查询资料、生成答复，并按权限保存必要的结果。

第一次读 Python 可以直接打开第 1 课。正文的源码节选都带读法。每课都有一道可在浏览器里完成的判断，想亲手查接口时，可以用第 01 篇的本机 Demo。最后一课把各步连成一次能复查的实验。 [启动工作台](../01-第一次跑起来.md)

| 顺序 | 篇章 | 做完能检查什么 |
| --- | --- | --- |
| 1 | [01-A 从界面找到源码入口](01-A-Agent工作流.md) | 读懂函数、字典和条件，把一次提问追到 `run_career_graph` |
| 2 | [01-A1 请求与状态](01-A1-请求与状态.md) | 写出一份请求，说明同为 422 的两种原因，把输入对上图状态 |
| 3 | [01-A2 路由与结束条件](01-A2-路由与结束条件.md) | 画出三条出口，预测两个关键词同时出现时先走哪条 |
| 4 | [01-B 工具调用](01-B-工具调用.md) | 说出检索的参数和返回值，从命中的 ID 查回原文 |
| 5 | [01-B1 模型答复与引用](01-B1-模型答复与引用.md) | 分清模板、分析快照和普通模型答复，定位引用错误如何回退 |
| 6 | [01-B2 会话与画像确认](01-B2-会话与画像确认.md) | 用同一会话继续提问，分别检查聊天记录和长期画像 |
| 7 | [01-C Coordinator 与子 Agent](01-C-子Agent.md) | 读出两个角色各拿什么、怎样限次、最后由谁提交 |
| 8 | [01-D 综合跟做](01-D-综合跟做.md) | 用一份资料复跑请求、引用、会话和后台步骤，留下可复查的记录 |

读完之后用一组自己的话说一遍。比如「接口读到画像后把问题交给图，图选择检索，工具交回原文，答复再核对使用的编号」。能指到每个动作的源码位置，就可以继续看记录怎样存下来。 [进入数据模型](../02-数据模型.md)
