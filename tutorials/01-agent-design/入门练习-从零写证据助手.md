# 从空目录写一个证据助手

为什么问「用过 Kubernetes 吗」时，查到了「收藏教程」却仍要回答证据不足？这次你写一条最小路径：保存原文、查候选、判断是否能引用、返回编号。阅读约 12 分钟，动手约 20 分钟。代码保存在自己的练习目录。只看输入输出的读者也可以完成文末挑战。 [环境准备](../setup/动手准备.md)

## 第二步：让小写查询找到原句

先把 `query.casefold()` 存成 `needle`。遍历 `records` 时，把每条 `record["content"]` 也用 `casefold()` 处理。如果 `needle in ...` 成立，就把原记录加入结果。返回整条记录，后面还要用它的 `id` 和 `kind`。

重跑检查。第一条会通过，下一条错误应移到 `reply`。这时你已经能用查询词找回原文。

<details>
<summary>核对 find_evidence 的写法</summary>

```python
def find_evidence(records, query):
    needle = query.casefold()
    return [row for row in records if needle in row["content"].casefold()]
```

</details>

## 第三步：把候选编号与引用编号分开

在 `reply` 里用 `find_evidence` 得到 `hits`。候选全部保留 ID。只有 `kind == "experience"` 的候选放入 `supported`。有经历记录时将 `status` 设为 `supported`，把经历编号放在 `citation_ids`。没有时交回空的引用列表和 `gap`。先猜一下：如果再导入一份练习集群的部署记录，Kubernetes 的候选列表和引用列表各添哪一项？

<details>
<summary>核对 reply 的写法</summary>

```python
def reply(records, query):
    hits = find_evidence(records, query)
    supported = [row for row in hits if row["kind"] == "experience"]
    return {
        "status": "supported" if supported else "gap",
        "candidate_ids": [row["id"] for row in hits],
        "citation_ids": [row["id"] for row in supported],
        "answer": supported[0]["content"] if supported else "当前材料缺少实际经历。",
    }
```

</details>

## 选做：让浏览器调用你刚写的两个函数

完成[动手准备](../setup/动手准备.md#给源码练习准备一套-python)后，在练习文件夹新建 `mini_api.py`。用 Pydantic 对 JSON 请求做类型校验，用 FastAPI 将地址交给对应函数。

```python
from typing import Literal

from fastapi import FastAPI
from pydantic import BaseModel, Field

from assistant_core import add_evidence, reply

app = FastAPI()
records = []


class EvidenceInput(BaseModel):
    content: str = Field(min_length=1)
    kind: Literal["experience", "preference"]


class Question(BaseModel):
    query: str = Field(min_length=1)


@app.post("/evidence", status_code=201)
def add(payload: EvidenceInput):
    return add_evidence(records, payload.content, payload.kind)


@app.post("/ask")
def ask(payload: Question):
    return reply(records, payload.query)
```

在项目根运行 `python -m uvicorn mini_api:app --app-dir .cache/mini-careerlens --host 127.0.0.1 --port 8032`。打开 [练习 Swagger](http://127.0.0.1:8032/docs)，向 `POST /evidence` 提交 `{"content":"林澈收藏了 Kubernetes 部署教程","kind":"preference"}`，再向 `POST /ask` 提交 `{"query":"Kubernetes"}`。核对拿到的候选 ID 与原文编号相同。把 `kind` 改成 `unknown` 再提交，会得到 422，这次保存函数不会执行。结束后按 Ctrl+C。这个小服务用进程中的列表存材料，重启后重新导入即可。
