# CareerLens 学习路线

跟着林澈的实习申请做一次证据判断，直到你能读懂工作台背后的代码。第一次来，可以[先做 3 分钟的证据题](从这里开始.md#先做一道证据题)，或直接[开始 00-1](00-foundations/00-1-Agent是什么.md)。

## 学习路径

从上到下学，每篇末尾都有下一课。前四篇用浏览器即可。已经跑通工作台的读者可以从 Agent 源码开始。

| 顺序 | 依次阅读 | 做完能检查什么 |
| --- | --- | --- |
| 1. 学概念 | [00-1 Agent 是什么](00-foundations/00-1-Agent是什么.md) → [00-2 提示词与证据](00-foundations/00-2-提示词与证据.md) → [00-3 RAG 与检索](00-foundations/00-3-RAG与检索.md) → [00-4 数据模型](00-foundations/00-4-数据模型大白话.md) | 给两条结论找依据，再从报告的编号追回原文 |
| 2. 跑一遍产品 | [01 第一次跑起来](01-第一次跑起来.md) | 从工作台打开一次岗位分析，找到一条依据和一个缺口 |
| 3. 读 Agent 源码 | [从 01-A 开始](01-agent-design/01-A-Agent工作流.md) · [八节课目录](01-agent-design/README.md) | 从一次提问追到源码入口、状态、分支、工具、模型答复、会话保存和子 Agent；最后跟做一份完整记录 |
| 4. 读数据与知识库 | [02 数据模型](02-数据模型.md) → [03 解析与去重](03-解析层.md) → [04 检索与引用](04-检索Agent.md) → [05 Wiki 知识库](05-Wiki知识组织.md) | 比较两份文件的来源，手算一次检索排名，从 Wiki 页找到原始证据 |
| 5. 跟一次任务和接入 | [06 后台运行时](06-后台运行时.md) → [07 匹配、排期与验证](07-接入与验证.md) → [07-A MCP 服务与 ACP 对照](07-A-MCP服务与ACP对照.md) | 续看一个 Run，复算一次排期，说明如何在 MCP 客户端读取报告 |

没有装过 Docker，第 01 篇从选择系统版本和确认安装开始。设备不能安装时，用[静态观察路线](静态观察路线.md)完成证据回溯，再进入 [01-A](01-agent-design/01-A-Agent工作流.md)读流程和做纸面练习。需要脚本时再[准备 Python](setup/Python准备.md)。

## 做一个别人能复跑的练习

学完上面的主线后，可以用 [08-2 评测](08-advanced/08-2-评测.md)比较两组检索结果，再按 [08-3 贡献与结课](08-advanced/08-3-贡献与结课.md)交付。想试模型配置时，先读 [08-1 真实模型](08-advanced/08-1-真实模型.md)。请在[结课模板](结课模板.md)中留下版本、合成输入、命令和一条反例，交给别人照做。
