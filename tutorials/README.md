# CareerLens 教程

林澈想申请一个岗位，手里有课程项目、自述和几份文档。我们从这些材料出发，看看一句结论怎样找到原文，又怎样变成匹配分和一份学习计划。

## 学习路径

第一次来，先分清你想**看懂**还是想**动手跑**。在 GitHub 上读时，直接点下面的第一篇，再用各篇末尾的「下一步」继续。

### 只用浏览器

从[第一道证据题](从这里开始.md#先做一道证据题)开始，再跟着 00-1 → 00-2 → 00-3 → 00-4 读。到 [00-4](00-foundations/00-4-数据模型大白话.md) 能从一条报告结论找到原文，就完成了这条路线。

### 跑通一次并看懂代码

1. [01 第一次跑起来](01-第一次跑起来.md)。看到工作台结果，找到一条有原文支持的匹配和一个缺口，便完成第一次实操。
2. 继续读 02 → 03 → 04 → 05 → 06，最后到 [07 匹配分和排期](07-接入与验证.md)。在那里核对同一岗位的分数和学习周数，就走完了核心篇。
3. 想做一个给别人复跑的作品，再到 [08-2 评测](08-advanced/08-2-评测.md)做一次对照，按[结课模板](结课模板.md)交输入、命令和结果。08-1 留给要接真实模型的读者。

设备装不了 Docker，可以用[静态观察路线](静态观察路线.md)看工作台输出。只想弄懂排名，可以直接从 [04 的手算](04-检索Agent.md)开始。
