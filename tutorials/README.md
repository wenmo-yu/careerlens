# CareerLens 学习路线

林澈申请实习，材料里写着做过 Python 项目，也收藏过 Kubernetes 教程。你能据此写出什么？[用 3 分钟做第一题](从这里开始.md#先做一道证据题)。做完可以先读四篇入门课，也可以立刻看系统怎么给出结果。

## 学习路径

浏览器即可做第一题和入门练习。想先体验工作台，直接读 [01 第一次跑起来](01-第一次跑起来.md)。设备无法安装软件时，走[静态观察路线](静态观察路线.md)，先在截图和原文里核对一次匹配。

| 顺序 | 依次阅读 | 做完能检查什么 |
| --- | --- | --- |
| 1. 学概念 | [第一章的八篇概念课](#第一章-学概念) | 写下两句有依据的结论，再从一个编号追回原文 |
| 2. 跑一遍产品 | [01 第一次跑起来](01-第一次跑起来.md) | 打开一次岗位分析，找到一条依据和一个缺口 |
| 3. 写并读 Agent 源码 | [动手准备](setup/动手准备.md) → [从空目录写证据助手](01-agent-design/入门练习-从零写证据助手.md) → [真实源码课目录](01-agent-design/README.md) | 先写一个小程序，再换到真实请求、工具、引用、会话和子 Agent |
| 4. 读数据与知识库 | [知识库练习目录](04-knowledge-base/README.md) → [02 数据模型](02-数据模型.md) | 让两份 DOCX 共用一条证据，做一页 Wiki 并追回两处原文 |
| 5. 跟一次任务和接入 | [06 后台运行时](06-后台运行时.md) → [07 匹配、排期与验证](07-接入与验证.md) → [07-A MCP 服务与 ACP 对照](07-A-MCP服务与ACP对照.md) | 用 Run ID 找回结果，复算一次排期，再让 MCP 客户端读取你生成的报告 |
| 6. 用证据做画像和学习计划 | [10 导入与可回查画像](10-导入与可回查画像.md) → [11 岗位对比与学习计划](11-岗位对比与学习计划.md) | 从技能追回作业，比较两份岗位的缺口，给第一周定一项作品 |

跑工作台时按第 01 篇装 Docker。进入源码和脚本练习时再[准备 Python](setup/Python准备.md)。每次换课要切换的服务、账号与数据，集中在[环境与编号表](setup/动手准备.md#核对环境与编号)。只想用新版功能练手，跑起服务后可以直接从第 10 篇开始。

八篇都可以用浏览器学习。建议先读前四篇，学会判断和追溯证据，再跑一次产品。后四篇也属于第一章，适合在读 Agent 和知识库源码前回看。

## 做一个别人能复跑的练习

选一个你愿意复查的问题，再交一份别人可以运行的结果。想换模型或追踪收藏误判，读 [08-1 真实模型](08-advanced/08-1-真实模型.md)。想量化排序变化，做 [08-2 评测](08-advanced/08-2-评测.md)。想看证据画像和自陈测评如何并存，做 [09 画像与自陈测评](09-画像与自陈测评.md)。最后从 [08-3 贡献与结课](08-advanced/08-3-贡献与结课.md)拿到要求，用[结课模板](结课模板.md)留下版本、合成输入、运行命令和一个失败对照。
