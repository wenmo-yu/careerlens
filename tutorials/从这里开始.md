# 从这里开始

林澈准备申请一份实习。跟着他的材料做一次岗位判断，你会从第一条证据一路读到 CareerLens 里负责检索、Wiki、子 Agent 和后台任务的代码。

- **第一次来**：[先做下面的 3 分钟证据题](#先做一道证据题)，再进 [00-1](00-foundations/00-1-Agent是什么.md)。前四篇只用浏览器，读完可以先跑产品。
- **想先体验产品**：[打开第 01 篇](01-第一次跑起来.md)，从检查电脑和安装 Docker 开始。装不了软件就[先看静态案例](静态观察路线.md)。
- **想亲手写代码**：[从动手准备开始](setup/动手准备.md)，先让一个短测试从失败变为通过，再用真实项目学工具和子 Agent。

[打开完整学习路径](README.md#学习路径)。在 GitHub 和在线站都可以沿每课末尾的「下一步」继续。

## 先做一道证据题

岗位要求 Python，优先考虑有 Kubernetes 上线经历的人。你手里只有林澈的三张卡。

| 卡片 | 原文 |
| --- | --- |
| A | 用 Python 做过课程项目 |
| B | 收藏了 Kubernetes 教程 |
| C | 课程项目只在本机演示 |

给林澈写两句你愿意签字的话。第一句讲 Python，第二句讲上线经验。每句都指出依据。这个练习约 3 分钟。

<details>
<summary>核对你的两句话</summary>

A 能确认林澈用 Python 做过课程项目。现有材料没有写到需要多熟练才能完成项目，先保持这个范围。

B 记录了收藏，C 限定在本机演示。写「当前材料不足以确认 Kubernetes 上线经验」即可，接下来可以补一份注明环境和步骤的部署记录。

</details>

带着这两句话去 [00-1 Agent 是什么](00-foundations/00-1-Agent是什么.md)。下一课会让一个助手自己按步骤查这三张卡。

## 什么时候需要安装软件

概念课和读图练习可以先用浏览器做。[第 01 篇的本机准备](01-第一次跑起来.md#步骤-1-本机准备)带你用 Docker 启动工作台和 Demo。进入脚本和源码课时，再打开[按系统准备 Python](setup/Python准备.md)。

设备无法安装 Docker，可以用[静态观察路线](静态观察路线.md)看预录结果，接着读 Agent 源码。遇到术语或配置问题时查[术语表](术语表.md)和[常见问题](常见问题.md)。
